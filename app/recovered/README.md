# Recovered application code drafts

This directory contains `.logic.js` module evidence, `.options.js` objects extracted from Vue component definitions, and `.vue` template drafts produced from render functions. These are complementary analysis outputs and are not yet a complete, standalone Vue project.

- `.logic.js`: formatted module evidence with production identifiers and Webpack wrapper.
- `.options.js`: extracted component options; some properties still reference Webpack aliases/imports.
- `.vue`: template draft with placeholder script section; not guaranteed to compile.

Use `../INDEX.md` and `../../indexes/recovery-index.json` to locate source chunks and modules.
